# UD2A1_miguel
Proyecto realizado por Miguel Bedmar alumno de segundo de desarrollo de aplicaciones multimedia.

# 📋 Descripcion.
La empresa ficticia BookShelf Pro desea desarrollar una aplicación de escritorio para
gestionar una colección personal de libros.

# 🎯 Objetivo.
Aprender a manejar C# y .NET utilizando visual studio comunity como ide de proyecto
para así conocer tecnologías mas  modernas y utilizadas en el entorno

# 🏛️ Requisitos.
  - Interfaz gráfica
      - DockPanel
      - TextBox(Titulo)
      - TextBox (Autor)
      - Button
      - DataGrid
  - UserControl: LibroCard
      - Titulo
      - Autor
      - Boton 
  - Añadir libro
      - Leer datos de los TextBox.
      - Validar que no estén vacíos.
      - Crear objeto Libro.
      - Añadirlo a la colección.
      - Actualizar DataGrid.
   
  - Mensajes de error
  - Usabilidad
    -   Botones con nombres claros.
    -   Etiquetas descriptivas.
    -   Flujo de navegación coherente
  - Accescibilidad
    - Contraste adecuado.
    - Fuente mínima 12 pt.
    - Navegación mediante teclado.
    - Uso correcto del foco.
